# Better Game Rules (Fabric, Minecraft 26.3)

Improves the Game Rules menu: search and type filters, pinning rules to the top of the list, named presets with a preset list, per-rule reset buttons and a reworked layout. Client-side only.

- [Modrinth](https://modrinth.com/mod/better-game-rules)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/better-game-rules)

## Building

Requires JDK 25.

```bash
./gradlew build
```

The built jar can be found in `build/libs/`.
